## 第一阶段：技术底座迁移（2026-10-13）

四个目录是独立 Git 仓库；第一阶段已分别提交并推送（管理前端 a74af58、社区前端 7e31808、管理后端 8b49665、社区后端 e5501ec）。根目录提供统一说明和验证脚本。

| 范围 | 原版本 | 迁移后 |
| --- | --- | --- |
| 两套前端 | Vue 2.6 / JavaScript / Vue CLI 4 | Vue 3.5.43 / TypeScript 5.9 strict / Vite 8.3 |
| 路由、状态 | Vue Router 3 / Vuex 3 | Vue Router 4 / Vuex 4（保留业务状态结构） |
| 组件库 | Element UI 2 / Buefy 0.9 | Element Plus 2 / Buefy 3（社区端） |
| 两套后端 | Java 11 / Boot 2.3、2.5 SNAPSHOT | JDK 21 / Spring Boot 3.5.16 |
| 管理数据层 | MyBatis Plus 3.4 | MyBatis Plus 3.5.17（Boot 3 starter） |
| 社区数据层 | Hibernate 5 / javax.persistence | Hibernate 6 / jakarta.persistence |
| JWT、文档 | JJWT 0.9 / Springfox | JJWT 0.12.6 / Springdoc 2.8 OpenAPI |

采用 Boot 3.5 作为旧系统迁移基线，避免同时引入 Boot 4 的额外大版本变化。Vue 使用迁移当天 npm 官方仓库的稳定版；TypeScript 5.9 是本次实际验证的工具链版本。
