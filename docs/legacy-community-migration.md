## 执行工具

在社区后端目录运行：

```bash
./mvnw -DskipTests package
# 先启动当前社区后端，使目标库执行至 Flyway V5。
python3 scripts/migrate_legacy.py
```

需要 Python 3、JDK 21 和可执行后端 JAR。工具复用 JAR 中的 MySQL JDBC 驱动，无需安装 Python 数据库依赖；读取 `.env.local` 的 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`，目标必须为 `liushao_community`，连接账号需有创建和删除临时数据库的权限。

可指定 `--source`、`--env-file`、`--source-offset`（默认 `+08:00`）和 `--report`。此工具转换当前仓库历史 SQL 的表结构；其他来源应先核对字段和来源时区。相同来源的已映射记录不会重复导入或覆盖；若有人删除已映射记录，工具也不会自动恢复该记录。

代码位于社区后端 `scripts/migrate_legacy.py`、`scripts/MigrateLegacyCommunity.java` 和 `scripts/import-legacy-community.sql`。默认 JSON 报告保存来源 SHA-256、逐表行数、异常处理数量及全部旧新 ID 映射，路径为本项目 `.artifacts/legacy-community-migration/import.json`；不保存数据库密码或令牌。
